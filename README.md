# Shoply — Colorful React E-commerce UI

A responsive e-commerce storefront made with React, Vite, and custom CSS animations.

## Features
- Responsive layout for desktop, tablet, and mobile
- Animated gradient hero, floating artwork, and product cards
- Product search, category filtering, and sorting
- Working shopping bag with quantity controls and subtotal
- Wishlist buttons and toast notifications
- Free delivery indicator for orders over Rs. 2,000
- Reduced-motion accessibility support

## Run locally
1. Install Node.js if it is not already installed.
2. Open this folder in VS Code.
3. Open a terminal in this folder and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Notes
This is a front-end demo. Checkout does not process payments, and products/cart are not saved after refresh. Product photos load from Unsplash. For a production store, connect a backend/database and a payment provider.
